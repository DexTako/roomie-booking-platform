### Step 2: Set Up the Project (One Time - 5 minutes)
```
1. Open Terminal/PowerShell in the roomie-prototype folder
   (Right-click folder → "Open in Terminal")

2. Type: npm install

3. Press Enter and wait (takes 2-3 minutes)
```

### Step 3: Test Run
```
1. In Terminal, type: npm run dev

2. Press Enter

3. Browser opens to http://localhost:3000

4. You should see:
   - Roomie navigation bar
   - Apartment details
   - 3D model of your apartment
   - Booking form on the right

5. Test the features:
   - Drag the 3D model (should rotate)
   - Fill out the booking form
   - Submit booking (should confirm)
   - See 3D model turn red

6. Stop the server: Press Ctrl+C in terminal
```

## If Something Goes Wrong

**3D Model Doesn't Load:**
- Refresh page (Ctrl+R)
- Check console (F12)
- Explain the feature using WHAT_YOU_GET.md diagrams

**Server Won't Start:**
- Delete `node_modules` folder
- Run `npm install` again
- Show code and screenshots instead

**Booking Doesn't Work:**
- Check console for errors
- Show the code logic instead
- Explain how it's supposed to work
