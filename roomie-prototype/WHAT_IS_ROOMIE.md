# What is Roomie?

**Roomie** is a modern room booking platform that helps users find and book their perfect stay with immersive 3D room tours, smart filters, and a seamless booking experience.

---

## Key Features

### 🏠 Room Discovery
- Browse curated room listings with detailed information
- Filter by price, capacity, amenities, and themes
- Search by location, name, or description
- View ratings and reviews from previous guests

### 🎨 Immersive 3D Tours
- Explore rooms with interactive 3D walkthroughs
- Navigate through different room areas (bedroom, kitchen, bathroom, etc.)
- Walk mode for realistic room exploration
- High-quality textures and lighting

### ❤️ Wishlist & Comparison
- Save favorite rooms to wishlist
- Compare up to 3 rooms side-by-side
- Quick access to saved and compared rooms
- Real-time counter badges

### 📅 Smart Booking
- 4-step booking wizard
- Date selection with availability checking
- Guest information collection
- Secure payment processing (demo mode)
- Booking confirmation and management

### ⭐ Reviews & Ratings
- Read detailed guest reviews
- Filter by rating and sort by date/helpfulness
- See category ratings (cleanliness, location, value, etc.)
- Rate reviews as helpful

### 👤 User Roles

**Renters:**
- Browse and book rooms
- Manage bookings
- Leave reviews
- Create wishlists

**Hosts:**
- Manage room listings
- View booking statistics
- Track earnings
- Respond to reviews

**Admins:**
- Manage all users and rooms
- Monitor platform statistics
- Handle disputes
- System configuration

---

## Technology Stack

- **Frontend:** React 18 with Vite
- **3D Graphics:** React Three Fiber (Three.js)
- **Styling:** Tailwind CSS with custom glassmorphic design
- **State Management:** React Context API
- **Storage:** LocalStorage (demo), ready for backend integration
- **Routing:** React Router (SPA)

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Start dev server: `npm run dev`
4. Open http://localhost:3000
5. Log in with demo accounts above
