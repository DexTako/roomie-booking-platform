# 🏠 Roomie Frontend

React-based frontend for the Roomie booking platform.

## 🚀 Quick Start

```bash
npm install
npm run dev
```

## 📁 Key Directories

- **`src/components/`** - Reusable UI components
- **`src/pages/`** - Application pages  
- **`src/context/`** - React context providers
- **`public/models/`** - 3D model files

## 🎯 Main Features

- **Authentication**: Login, register, forgot password
- **Booking System**: Room search, booking wizard, payments
- **3D Tours**: Interactive room viewers with Three.js
- **Reviews**: Rating and review system
- **Responsive Design**: Mobile-first approach

See main [README.md](../README.md) for complete documentation.
